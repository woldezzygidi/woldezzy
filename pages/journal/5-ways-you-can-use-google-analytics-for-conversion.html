5 Ways to Use Google Analytics 4 for Conversions: Key Events, Funnels and Attribution

By 'Wole Oduwole

The five ways I use Google Analytics 4 for conversions in 2026: mark the actions that matter as key events, find which landing pages produce them, use funnel explorations to see where people drop out, check attribution to see which channels earn them, and link Search Console to see which search queries lead to them. Before any of that, make sure consent mode is set up properly, or the numbers will mislead you.

I wrote the first version of this post in May 2022, using Universal Analytics. Goals, goal funnels, exit page reports and custom reports were the tools. All of them have gone. Universal Analytics stopped processing data in July 2023, Google deleted the remaining data in July 2024, and GA4 has since renamed the very thing this post is about. The idea behind the post still stands: use analytics to find where you are losing people, then fix it. The method is different, so this is a full rewrite.

Are conversions now called key events in GA4?

Yes. In March 2024 Google renamed "conversions" in GA4 to "key events". It is the change that confuses people most, so it is worth getting straight before anything else.

  • A key event is a GA4 event you have marked as important to your business: a purchase, a form submission, a phone click, a quote request. Key events are what you analyse inside GA4.
  • A conversion now means a conversion in the Google Ads sense: an action used to measure ad performance and to train bidding. In GA4 you create a Google Ads conversion from a key event, which needs a linked Google Ads account.

Google's own help page, Events and key events, explains the reason: before the change, the same action could be counted differently in GA4 and Google Ads, and the two numbers never matched. Separating the names makes the difference visible. If you do not run Google Ads, you only need key events.

Old reports and many tutorials still say "conversions". When you see it in a GA4 context from before 2024, read it as key events.

Before you start: can you trust the data?

Conversion analysis is only as good as the data under it, and two things have changed the data since 2022.

Consent. If you have visitors in the UK or the EU, many of them will decline analytics cookies. Google's consent mode tells Google tags what each visitor has agreed to. Version 2, which added the ad_user_data and ad_personalization signals, became a requirement in March 2024 for anyone using Google's advertising features with users in the European Economic Area. There are two ways to implement it:

  • Basic: Google tags do not load until the visitor consents. Visitors who decline are invisible.
  • Advanced: tags load with storage denied and send cookieless pings. GA4 can then estimate the missing behaviour with behavioural modelling, but only if the property qualifies. Google's thresholds include at least 1,000 events a day from visitors who declined, for at least seven days, and at least 1,000 consenting users a day on seven of the previous 28 days.

Most small and mid-sized sites do not meet those thresholds. So on a UK site with a typical consent banner, your GA4 key event counts are a sample, not a census. They are still very useful for comparing pages, channels and periods. They will not match your CRM or your order system, and they should not be expected to. Use your back-end figures for totals and GA4 for patterns.

Retention. GA4 standard properties keep event-level data for two months by default. Explorations, which three of the five methods below rely on, can only look back as far as that setting allows. Go to Admin, Data collection and modification, Data retention, and change it to 14 months. It only applies from the day you change it, so do it today.

1. Set up key events for the actions that matter

The old version of this post told you to create a goal. The GA4 equivalent is to make sure the right events exist and mark them as key events.

  1. List the actions that make you money or start a sales conversation. For a lead generation site that is usually form submissions, phone and email clicks, and booking confirmations. For ecommerce, purchase, and possibly begin_checkout. Keep the list short. If everything is a key event, nothing is.
  2. Check whether the events already exist. Open Admin, Events (under Data display). Enhanced measurement already records some interactions, such as file downloads and outbound clicks. Form tracking in enhanced measurement exists but is unreliable on many form builders, so test it.
  3. Create the missing events. For anything that is not recorded, set up an event in Google Tag Manager, or use Create event in GA4 to build one from an existing event, for example a page_view where the page location contains /thank-you/.
  4. Mark them as key events. In Admin, Key events, add the event name, or tick the star next to it in the Events list.
  5. Test. Use DebugView, or Realtime, while you complete the action yourself. Then check the counts against your form tool or order system after a week.
  6. If you run Google Ads, link the accounts and create Google Ads conversions from the key events you want to bid on.

Once key events are in place, GA4 also uses them to define engaged sessions, which is why they affect your bounce rate. I explain that link in how to reduce bounce rate in GA4.

2. Find which landing pages produce key events

This replaces the old landing page and exit page reports, and it is still the report I open first.

Go to Reports, Engagement, Landing page. Add Key events and Session key event rate as metrics if they are not already there, and set the key event filter to the one you care about, so a newsletter sign-up is not counted the same as a sales enquiry. Then add a comparison for Session default channel group equals Organic Search.

You are looking for two kinds of page:

  • High traffic, low key event rate. People arrive and do not act. Usually the page answers a different question from the one your offer solves, or the call to action is weak or buried. These are your biggest opportunities.
  • Low traffic, high key event rate. Pages that convert well but few people see. Link to them from your busier pages, and consider them for search and content investment.

Use the session-scoped key event rate here, not the user-scoped one. You want to know what happens on visits that start on this page.

3. Use funnel explorations to see where people drop out

In Universal Analytics, goal funnels had to be configured in advance and only showed data from that point onwards. GA4's funnel exploration works on data you already have, as far back as your retention setting allows.

  1. Go to Explore and choose Funnel exploration.
  2. Define your steps. For a lead form: landed on a service page, viewed the contact page, started the form (if you track form_start), submitted the form. For ecommerce: view_item, add_to_cart, begin_checkout, purchase.
  3. Choose open or closed. A closed funnel only counts people who entered at step one. An open funnel lets people join at any step, which is closer to how real visitors behave.
  4. Add a breakdown by Device category. In my experience the biggest single finding in most funnels is a mobile step that loses far more people than the same step on desktop.
  5. Turn on the elapsed time option to see how long each step takes.

Then use path exploration to look at what people do instead. Start from the step with the worst drop-off and look at the next pages they visit. If people leave your pricing page for your FAQ and never come back, the FAQ is answering a question the pricing page should have. Path exploration also runs backwards: choose a key event as the end point and see the pages people viewed before it.

4. Check attribution to see which channels earn key events

GA4 reports key events against the channel that brought the session, but the default reports and the Advertising section use different attribution, which is why figures disagree between screens.

The attribution options have narrowed. In 2023 Google removed the rule-based models, first click, linear, time decay and position-based, from both Google Ads and GA4. In GA4 you can now choose data-driven attribution, which is the default, a paid and organic last click model, or a Google paid channels last click model. You set the reporting model in Admin, Attribution settings.

How I use this:

  • Advertising, Attribution, Attribution paths shows which channels tend to start, assist and close paths that end in a key event. Organic search and referral often look much more valuable here than in last click reports, because they introduce people who convert later through direct or branded search.
  • Model comparison lets you compare data-driven with last click on the same key event. A channel that gains a lot under data-driven is doing work that last click hides.
  • Do not over-trust any model. Data-driven attribution can only credit touchpoints GA4 can see. Recommendations in a WhatsApp group, a podcast, an AI assistant's answer, a conversation at a conference: none of that is visible. I wrote about that gap in the dark funnel. Ask "how did you hear about us?" on your forms as well.

5. Link Search Console to see which queries lead to key events

This is the most underused integration in GA4 and the one I care most about as an SEO. Search Console tells you which queries bring clicks. GA4 tells you what those visitors did. Linking them lets you see both, by landing page.

  1. In GA4, go to Admin, Product links, Search Console links, and link the Search Console property to your web data stream. You need to be a verified owner in Search Console and have edit access in GA4.
  2. Go to Reports, Library, and publish the Search Console collection so it appears in your navigation. It contains two reports: Queries and Google organic search traffic.
  3. Open Google organic search traffic. It shows landing pages with Search Console impressions, clicks and position alongside GA4 engagement and key events.

The Queries report cannot show key events per query, because GA4 does not know which query an individual visitor used. The landing page view is where the value is. Sort by organic clicks and add key event rate. A page ranking well for many queries with a low key event rate needs a better offer or a better path to the offer. A page with a high key event rate and modest rankings is where more SEO work will pay back fastest. That is the sort of prioritisation I describe in scaling your business with SEO.

What about demographics and custom reports?

The 2022 version recommended demographic reports and custom reports. Both exist in GA4 in some form, with limits. Demographic and interest data needs Google signals to be turned on, and GA4 applies thresholding, hiding rows where the number of users is small enough that individuals could be identified. On smaller sites, so much is withheld that the reports are not useful for conversion work.

Custom reports are now explorations, covered above, plus the ability to customise the standard reports and add them to your navigation. If you need dashboards for a team, connect GA4 to Looker Studio, or export to BigQuery, which is free to link for standard properties within the export limits.

Quick answers

What is the difference between a key event and a conversion in GA4?
A key event is an important action you measure in GA4. A conversion is a Google Ads conversion created from a key event and used for ad measurement and bidding.

Why don't my GA4 key events match my sales figures?
Consent choices, ad blockers, cross-device visits and tracking gaps all mean GA4 sees a subset of activity. Use your order system or CRM for totals and GA4 for comparisons.

Can I still use first click attribution in GA4?
No. Google removed first click, linear, time decay and position-based models in 2023. Attribution paths in the Advertising section show which channels start the path to a key event.

How many key events should I have?
As few as describe the actions that matter to the business. For most small business sites that is two to five.

Start with the first method this week. Mark the two or three actions that make you money as key events, test them, and change data retention to 14 months. In a month you will have enough data for the other four.
